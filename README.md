# MXP Planos

Editor de planos eléctricos y arquitectónicos de Max Power Electrical Solutions, Inc.
Dibujo tipo Bluebeam/CAD: paredes, símbolos IEEE, riser diagrams, panel schedules,
medidas a escala real, takeoff automático y sets multi-hoja.

App web instalable (PWA) — funciona sin internet una vez instalada.
